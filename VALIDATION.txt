IMPLEMENTED / SOURCE-CONTRACT CHECKS

PASS - Release identifiers are firmware 2.0.0, Android 2.0.0, versionCode 20.
PASS - Wake modes are Interval = 0 and Smart = 1; the six persisted Interval
       values remain 60, 900, 1800, 3600, 7200, and 10800 seconds.
PASS - Smart mode retains the saved interval while selected; legacy
       CMD_SET_INTERVAL (0x05) selects Interval mode.
PASS - v2 protocol IDs are CMD_GET_SMART_INFO = 0x06,
       CMD_SET_SMART_CONFIG = 0x07, and RSP_SMART_INFO = 0x85.
PASS - CMD_SET_SMART_CONFIG has exactly the two-byte mode:u8,
       sensitivity:u8 payload; RSP_SMART_INFO has exactly 12 bytes in the
       documented field order.
PASS - The legacy 65-byte INFO response and existing log record layout remain
       compatible with earlier clients.
PASS - Metadata version 2 consumes two reserved bytes for wakeMode and
       smartSensitivity; version-1 migration defaults to Interval/Balanced and
       preserves owner identity and interval.
PASS - Owner reset clears ownership only and preserves route history, interval,
       wake mode, and Smart sensitivity. Clear-log preserves wake settings.
PASS - Smart source contract covers MPU candidate interrupt, 20 Hz / 5-second
       dynamic-acceleration verification, fresh UTC location acquisition, and
       cooldown/reconfirmation behavior.
PASS - GPS status distinguishes physical supply, receiver activity, UART/parser
       activity, and timed standby; no physical-GPS-power-off capability is
       claimed for the assembled wiring.
